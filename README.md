# MarketPulse

Учебный ETL-проект для загрузки исторических данных маркетплейса Olist в PostgreSQL и подготовки аналитических витрин.

## Стек

- Python 3.12+
- PostgreSQL
- Docker Compose

## Статус

В разработке. Сейчас настраивается окружение проекта и база данных.

## Данные

Проект использует датасет Olist. Исходные CSV хранятся локально в `data/raw` и не коммитятся в Git.
